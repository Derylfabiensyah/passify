# Passify forest-glass direction

Source direction: forest reference supplied by the product owner, with #394032, #454F2D, #797F3E, #534332, and #9F7E4A.

Reading this as: a white-label ticketing platform for visitors and organizers, in a calm forest-at-dusk visual language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- Palette: forest deep, olive, and moss carry navigation and structure; gold is reserved for the booking action so the primary decision is easy to find.
- Typography: Plus Jakarta Sans keeps public information and field operations legible at compact sizes across web and mobile.
- Surfaces: warm neutral backgrounds keep transactional content readable while the palette provides the product identity.
- Glass: translucent blur is used only for the public availability summary and the organizer's template preview, where a layered view supports context without reducing hierarchy elsewhere.
- Layout: the public portal leads with booking context, then tickets, then optional visitor information; the organizer editor separates content, palette, and visibility controls so changes are easy to understand.
- Motion: controls use brief native hover and press feedback only; no continuous decorative animation is part of the direction.
